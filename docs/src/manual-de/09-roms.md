# Ein ROM oder das originale Integer BASIC installieren

<p class="lead">Nichts weiter ist nötig. Der Woz Monitor, das Kassetten-ROM der ACI und RDK G2 Basic sind bereits im Programm. Diese Seite ist für alle, die Apples Integer BASIC oder ein anderes kompatibles ROM aus einer externen Quelle möchten.</p>

Der Kit **verbreitet keine proprietäre ROM-Datei weiter**. Der Apple-1, das Integer BASIC von 1976 und die kommerziellen Kassetten bleiben bei ihren Rechteinhabern. Die Links unten zeigen auf bereits bestehende Seiten: Dort holen Sie Ihre eigene Kopie. Der Kit enthält sie nicht.

## Was bereits eingebaut ist

- **Woz Monitor**, bei `$FF00`.
- **Kassetten-ROM der ACI**, bei `$C100`.
- **RDK G2 Basic**, ein freies, zum Integer BASIC kompatibles BASIC, das die Schaltfläche **BASIC** nach `$E000` lädt.

## Das originale Integer BASIC

1. Besorgen Sie sich Ihre eigene Kopie, zum Beispiel die Kassette `BASIC.wav` aus der Sammlung „Apple1Cassettes“ auf archive.org: <https://archive.org/details/Apple1Cassettes>.
2. Legen Sie die Datei in Ihre Bibliothek, oder bewahren Sie sie auf, wo Sie möchten.
3. Öffnen Sie **⚙ Einstellungen → Erweitert → BASIC**, wählen Sie **Original-Integer-BASIC**, dann **📂 Wählen…**, und zeigen Sie auf die Datei (eine `.wav`, eine `.txt` oder eine `.bin` von 4096 Bytes).
4. Die Schaltfläche **BASIC** lädt dann diese Datei. **Vergessen** kehrt zum eingebauten G2 Basic zurück.

Die Apple-1-Gemeinschaft trifft sich auf <https://www.applefritter.com/>. Der Kit lädt nichts von diesen Seiten herunter: Der Link ist nur ein Hinweis.
