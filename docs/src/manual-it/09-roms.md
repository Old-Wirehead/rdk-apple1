# Installare una ROM o l'Integer BASIC originale

<p class="lead">Non serve nient'altro. Il Woz Monitor, la ROM della cassetta dell'ACI e RDK G2 Basic sono già nel programma. Questa pagina è per chi vuole l'Integer BASIC di Apple, o un'altra ROM compatibile, da una fonte esterna.</p>

Il kit **non ridistribuisce alcun file ROM proprietario**. L'Apple-1, l'Integer BASIC del 1976 e le cassette commerciali restano ai loro titolari dei diritti. I link qui sotto puntano a siti che esistono già: lì vi procurate la vostra copia. Il kit non la contiene.

## Che cosa è già integrato

- **Woz Monitor**, in `$FF00`.
- **ROM della cassetta dell'ACI**, in `$C100`.
- **RDK G2 Basic**, un BASIC libero compatibile con Integer BASIC, caricato in `$E000` dal pulsante **BASIC**.

## L'Integer BASIC originale

1. Procuratevi la vostra copia, per esempio la cassetta `BASIC.wav` della raccolta «Apple1Cassettes» su archive.org: <https://archive.org/details/Apple1Cassettes>.
2. Mettete il file nella libreria, o tenetelo dove preferite.
3. Aprite **⚙ Preferenze → Avanzate → BASIC**, scegliete **Integer BASIC originale**, poi **📂 Scegli…** e indicate il file (un `.wav`, un `.txt` o un `.bin` di 4096 byte).
4. Il pulsante **BASIC** carica allora quel file. **Dimentica** torna al G2 Basic integrato.

La comunità dell'Apple-1 si ritrova su <https://www.applefritter.com/>. Il kit non scarica nulla da questi siti: il link è solo un'indicazione.
