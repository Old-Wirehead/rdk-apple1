# Первые шаги в BASIC

<p class="lead">Integer BASIC для Apple-1 умещается в 4 КБ. Он знает только целые числа, имена переменных из одной буквы, и в нём нет ни DATA, ни строковых функций: он маленький, быстрый и полон ловушек.</p>

!!! apple1 "Откуда взялся этот BASIC"
    Стив Возняк написал его в 1976 году вручную, на языке ассемблера, без компьютера, на котором его можно было бы ассемблировать. Он продавался на кассете (75 $) и загружается в `$E000-$EFFF`. Эмулятор не поставляет оригинал от Apple: если он вам нужен, используйте свой `BASIC.wav` или образ размером 4 КБ (глава 4). Все проверки в этой части выполнены в эмуляторе, с этим оригиналом.

## Два BASIC: RDK G2 Basic и оригинал

Начиная с версии 7.9 у эмулятора есть собственный BASIC — **RDK G2 Basic**, встроенный в программу. Это клон Integer BASIC по методу «чистой комнаты», написанный с нуля на ассемблере 6502 (в нём нет кода интерпретатора Apple) и распространяемый под лицензией MIT. Он посвящён Uncle Bernie.

- **Совместимый**: тот же синтаксис, те же токены, тот же формат программы в памяти, тот же формат кассеты. Программы, листинги и кассеты, написанные для оригинала, работают без изменений. Он сверен с оригиналом на 22 сеансах проверки с одинаковым выводом.
- **Исправленный**: известные ошибки оригинала, описанные в главе 18, исправлены.
- **Больше**: 7 933 байта вместо 4 КБ. Ему нужно ОЗУ от `$E000` до `$FEFF`; эмулятор его даёт, но в окно EPROM размером 4 КБ, как у оригинала, он бы не поместился.
- **Знает GEN2**: при запуске он ищет карту GEN2 и, если находит, запускает драйвер карты (а затем ставит LOMEM в `$2000`, выше графических страниц). Сами графические операторы запланированы для версии 2 G2 Basic.
- **Заставка**: `RDK G2 BASIC 1.0`, затем `DEDICATED TO UNCLE BERNIE`.
- **Расширенный** (версия 7.9.2): `LOMEM=` и `HIMEM=` работают как в оригинале, а новая функция **`KEY(n)`** читает клавиатуру без ожидания, чтобы игра могла смотреть на клавиши, не блокируясь на `INPUT` и не останавливаясь от нажатия клавиши (глава 15). `LIST a,b` и `DEL a,b` используют диапазоны оригинала, а выводимая строка длиннее экрана переносится так же, как в оригинале.

Кнопка **BASIC** загружает G2 Basic. Чтобы вместо него использовать оригинал Apple, откройте **⚙ Настройки → Дополнительно → BASIC**, выберите **Оригинальный Integer BASIC (ваш собственный файл, загружаемый в $E000)** и укажите файл; выбор запоминается, и тогда кнопка загружает его. Оба ведут себя одинаково во всём, что описано в этой части; различия отмечены там, где они важны (HIMEM при запуске, ошибки главы 18).

!!! note "Исходный код и тесты"
    У G2 Basic есть собственный репозиторий, `Old-Wirehead/rdk-gen2basic-apple1`, с его руководством, исходным кодом и регрессионными тестами.

## Запуск BASIC

Щёлкните **BASIC** на панели инструментов: эмулятор загружает выбранный вами BASIC (по умолчанию G2 Basic), а вы запускаете его командой `E000R`. Приглашение BASIC — `>`, приглашение Woz Monitor — `\`.

```mon
\
» E000R
E000: 4C
>
```

- `E000R`: **холодный запуск**, стирает программу в памяти.
- `E2B3R`: **тёплый запуск**, сохраняет программу. Этот адрес нужен после загрузки программы с кассеты и для возврата в BASIC после захода в монитор (RESET).

## Прямой режим и режим программы

Строка, которая начинается с **числа** (от 0 до 32767), сохраняется в программе; строка без номера выполняется сразу.

```mon
>» PRINT 2*3+4*5
26
>» 10 PRINT "HELLO"
>» 20 GOTO 10
>» RUN
HELLO
HELLO
…
```

Нажмите любую клавишу, чтобы остановить программу: BASIC выведет `STOPPED AT 10`. Повторный ввод строки с тем же номером заменяет её; номер без текста удаляет её.

!!! attention "Прямой режим ограничен"
    В прямом режиме BASIC отвергает операторы, разделённые `:` (`SYNTAX ERR`), а также `FOR` и `GOSUB`. Чтобы попробовать цикл, запишите его в нумерованной строке.

## Исправление строки

На клавиатуре Apple-1 нет клавиши удаления: **Backspace** эмулятора набирает `_`, что отменяет предыдущий символ (строка на экране не исправляется, но BASIC получает правильную). <kbd>Esc</kbd> отменяет всю строку: BASIC выводит `\` и ждёт следующую строку. Для удобной правки используйте редактор (глава 7): он раскрашивает синтаксис, сообщает об ошибках до отправки и набирает программу за вас.

## Команды

| Команда | Действие |
|---|---|
| {{LIST}} `[n[,m]]` | выводит программу, строку `n` или строки с `n` по `m` |
| {{RUN}} `[n]` | очищает переменные и запускает программу, со строки `n`, если она указана |
| {{DEL}} `n[,m]` | удаляет строку `n` или строки с `n` по `m` |
| {{SCR}} | стирает программу и переменные |
| {{CLR}} | очищает переменные, сохраняя программу |
| {{AUTO}} `n[,шаг]` | автоматическая нумерация с `n` (по умолчанию шаг 10); выход — <kbd>Ctrl</kbd>+<kbd>D</kbd>, затем <kbd>RETURN</kbd>, но не <kbd>Esc</kbd> |
| {{MAN}} | возвращает ручную нумерацию |
| {{HIMEM}}`=n`, {{LOMEM}}`=n` | границы памяти BASIC (глава 16) |

`GOTO n` в прямом режиме продолжает остановленную программу, **не** очищая переменные, в отличие от `RUN n`.

!!! astuce "LIST и медленный вывод"
    Терминал Apple-1 выводит около 60 символов в секунду: вывод длинной программы занимает время. Отключите ограничение вывода (**Быстрый** в строке отображения или в строке состояния), чтобы читать быстрее, или выводите по частям: `LIST 100,200`.
