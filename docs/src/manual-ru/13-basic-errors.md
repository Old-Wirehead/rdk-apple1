# Сообщения об ошибках и ограничения

## Сообщения

Ошибка выводит `*** СООБЩЕНИЕ ERR`, а если работает программа — затем `STOPPED AT n`. Строка, отвергнутая при вводе, не сохраняется: наберите её заново.

| Сообщение | Причина | Проверенный пример |
|---|---|---|
| {{SYNTAX ERR}} | неизвестный оператор, недопустимое имя переменной, `:` в прямом режиме | `CNT=7`, `GET A$`, `X=5:PRINT X` в прямом режиме |
| {{>32767 ERR}} | переполнение, деление на ноль, номер строки > 32767 | `200*200`, `10/0`, `RND(0)`, `32768 PRINT` |
| {{TOO LONG ERR}} | строка слишком сложная (слишком глубоко вложенное выражение) или слишком длинная | 13 вложенных скобок |
| {{MEM FULL ERR}} | между переменными и программой больше нет места | `DIM A(3000)` в 8 КБ |
| {{TOO MANY PARENS ERR}} | скобки (предусмотрено интерпретатором; маскируется ошибкой 3) | — |
| {{STRING ERR}} | неправильное использование строки | — |
| {{END ERR}} | программа заканчивается без `END` | `10 PRINT "X"`, затем `RUN` |
| {{BAD BRANCH ERR}} | `GOTO`/`GOSUB` на несуществующую строку | `GOTO 500` |
| {{>8 GOSUBS ERR}} | больше 8 вложенных `GOSUB` | рекурсия: 9 вызовов |
| {{BAD RETURN ERR}} | `RETURN` без `GOSUB` | `RUN 30` на строке с `RETURN` |
| {{>8 FORS ERR}} | больше 8 вложенных `FOR` или ошибка 1 | 9 циклов в одной строке |
| {{BAD NEXT ERR}} | `NEXT` без соответствующего `FOR` | один `20 NEXT I` |
| {{STOPPED AT}} | во время работы была нажата клавиша | — |
| {{>255 ERR}} | значение > 255: `POKE`, `DIM` строки | `POKE 768,300`, `DIM B$(256)` |
| {{RANGE ERR}} | индекс массива вне границ | `A(0)`, `A(3)` после `DIM A(2)` |
| {{DIM ERR}} | массив или строка объявлены повторно | — |
| {{STR OVFL ERR}} | строка длиннее своего `DIM` | `A$="ABCDE"` при `DIM A$(3)` |
| {{RETYPE LINE}} | недопустимый ответ на `INPUT` (буквы вместо числа): наберите заново | — |

Строки с «—» взяты из таблицы сообщений интерпретатора; в наших проверках они не вызывались.

## Ограничения

| Ограничение | Значение |
|---|---|
| целые | от −32767 до 32767 |
| номера строк | от 0 до 32767 |
| имена переменных | буква + необязательная цифра |
| имена строк | одна буква + `$` |
| длина строки | 255 |
| измерения массива | 1, индексы от 1 до n |
| вложенные `FOR` | 8 |
| вложенные `GOSUB` | 8 |
| вложенные скобки | 12 |
| длина набранной строки | 120 символов проходят, 141 отвергается |


## Экономия памяти

В 8 КБ у BASIC около 2 КБ на программу и переменные. Несколько способов выиграть место:

<ol class="steps">
<li><strong>Опустите LOMEM</strong>, если у вас нет машинного кода: <code>LOMEM=768</code> (<code>$0300</code>) даёт переменным ещё 1280 байт. Проверено: <code>DIM T(1200)</code> завершается <code>MEM FULL</code> с LOMEM по умолчанию и проходит после <code>LOMEM=768</code>. Так и поступают переносы игр из *101 BASIC Computer Games*, сделанные во время разработки.</li>
<li><strong>Пишите кратко</strong>: BASIC хранит пробелы и <code>REM</code>. <code>LIST</code> сам расставляет отступы, а одна длинная строка с несколькими операторами обходится дешевле, чем несколько строк.</li>
<li><strong>Используйте массивы и строки повторно</strong>, а не объявляйте новые.</li>
<li><strong>Добавьте ОЗУ</strong>: параметры ⚙ программы, <code>--ram 16</code> или настоящее расширение. Программе больше 8 КБ нужна машина на 12, 16 или 32 КБ: <code>apple1-emu basic --ram 16</code> размещает её в верхней части этой памяти.</li>
</ol>
