# Командная строка

<p class="lead">Две программы: apple1-emu-gui — графический интерфейс, и apple1-emu — эмулятор в терминале и набор инструментов для преобразования. Всё, что делают кнопки экспорта, можно сделать и из командной строки, для ваших скриптов.</p>

!!! attention "Инструменты командной строки говорят по-французски"
    Графический интерфейс доступен на русском (`--langue ru`), но `apple1-emu` выводит сообщения и справку только по-французски, а параметры графического интерфейса, команды F2 и ключевые слова отладчика — французские слова (`--carte-couleur`, `charger`, `pas`…). В этой главе показан настоящий вывод, с переводом там, где нужно.

## Эмулятор в терминале

`apple1-emu` без команды запускает Apple-1 в терминале (не меньше 42 столбцов × 28 строк): 8 КБ ОЗУ плюс `$E000`, ACI, реальная скорость.

```sh
apple1-emu                                  # 8 КБ + E000, ACI, реальная скорость
apple1-emu --fast                           # запуск в быстром режиме
apple1-emu --load samples/hello.txt --run 300
apple1-emu --tape samples/hello.wav         # кассета в виртуальной деке
apple1-emu --basic ~/apple1/integer_basic.bin
apple1-emu --ram 32 --no-e000               # 32 КБ, без ОЗУ в E000
```

| Параметр | Действие |
|---|---|
| `--ram KB` | ОЗУ с `$0000`, от 4 до 48 КБ (по умолчанию 8) |
| `--no-e000` | без ОЗУ в `$E000-$EFFF` (перемычка «W → E» на плате) |
| `--no-aci` | без кассетной карты |
| `--basic FILE` | ваш Integer BASIC (двоичный файл 4 КБ или шестнадцатеричный дамп), загружается в `$E000` |
| `--load FILE[@ADDR]` | программа в память (`.txt`, `.bin@ADDR`, `.wav`, `.aif`); можно повторять |
| `--tape FILE` | кассета в деке |
| `--type FILE` | набирает текстовый файл при запуске |
| `--run ADDR` | набирает `ADDRR` после загрузки |
| `--fast`, `--no-throttle` | быстрый режим; вывод без ограничения 60 символов/с |
| `--no-refresh` | без модели регенерации DRAM (1,0227 МГц вместо 0,960) |
| `--carte-couleur`, `--couleur-50hz` | карта GEN2 (регистры и память; цветное изображение есть только в графическом интерфейсе) |
| `--cursor-hz HZ`, `--cursor-duty F` | мигание курсора (по умолчанию 2,18 Гц, виден 2/3 времени) |
| `--monitor-rom`, `--monitor-page` | другой образ Woz Monitor (256 или 512 байт, страница 0 или 1) |
| `--aci-rom`, `--aci-page` | другой образ ППЗУ ACI |

**Клавиши терминала.** <kbd>Ctrl</kbd>+<kbd>R</kbd> — RESET, <kbd>Ctrl</kbd>+<kbd>L</kbd> — CLEAR SCREEN, <kbd>F1</kbd> — справка, <kbd>F2</kbd> — командная строка, <kbd>F3</kbd> — скорость, <kbd>F4</kbd> — ограничение вывода, <kbd>F5</kbd>/<kbd>F6</kbd> — воспроизведение/стоп кассеты, <kbd>F10</kbd> или <kbd>Ctrl</kbd>+<kbd>Q</kbd> — выход. Текст, вставленный в терминал, набирается на клавиатуре Apple-1. Backspace набирает `_` — знак стирания Woz Monitor.

**Команды F2** (слова команд французские).

| Команда | Действие |
|---|---|
| {{charger}} `FILE[@ADDR]` | *загрузить*: загружает в память `.txt`, `.bin` (нужен `@ADDR`), `.wav` или `.aiff` |
| {{sauver}} `FILE START.END …` | *сохранить*: сохраняет память; формат выбирается по расширению. Диапазоны можно скопировать из строки ACI: `sauver st.aiff 004A.00FFR 0300.0FFFR` |
| {{cassette}} `FILE` | *кассета*: вставляет кассету, которая запускается при первом чтении ACI |
| `lecture`, `stop`, `rembobiner`, `ejecter` | дека: воспроизведение, стоп, перемотка, извлечение |
| {{enregistrer}} `FILE` | *записать*: взводит запись; затем наберите `C100R` и `0300.03FFW` |
| `basic FILE` | загружает ваш Integer BASIC в `$E000` |
| `taper FILE` | *набрать*: набирает текстовый файл на клавиатуре |
| `reset`, `effacer`, `rapide`, `reel`, `debit`, `aide`, `quitter` | сброс, очистка, быстро, реальная скорость, скорость вывода, справка, выход |

## Преобразования

Формат вывода выбирается по **расширению**: `.aif`/`.aiff` даёт AIFF (профиль для смартфона), `.wav` — WAV, `.txt`/`.hex` — дамп Woz, `.bin` — двоичный файл.

{{export}} (псевдоним `export-wav`) создаёт кассету. Сигнал создаётся настоящим ПЗУ ACI, работающим в эмулируемом 6502: длительности битов — те же, что у Apple-1, выполняющего `W`.

```sh
apple1-emu export samples/hello.txt -o hello.aiff
apple1-emu export prog.bin@300 -o prog.wav --rate 48000 --bits 16
apple1-emu export startrek.txt --range "004A.00FFR 0300.0FFFR" -o startrek.aiff
```

| Параметр | WAV (по умолчанию) | AIFF (по умолчанию) |
|---|---|---|
| `--rate` | 44 100 Гц | 48 000 Гц |
| `--bits 8\|16` | 16 | 16 |
| `--channels 1\|2` | 1 | 2, одинаковых |
| `--amplitude` (от 0,05 до 1) | 0,8 | 0,89 (−1 dBFS) |
| `--silence S` | 0,5 с | 1,0 с |
| `--range` | один диапазон или целая строка ACI; можно повторять | |
| `--no-refresh`, `--no-embed` | биты на 6 % короче; без адресов в файле | |

{{import}} (псевдоним `import-wav`) декодирует кассету: `-o prog.txt` или `-o prog.bin`, `--addr ADDR` для кассеты без адресов, `--range`, чтобы разместить несколько записей.

{{info}} описывает файл (записи, адреса, длина); с `--aci-input stock|mimeo|gen2`, `--volts` и `--series` он моделирует аналоговый вход ACI (раздел 5.8).

{{convert}} `INPUT OUTPUT` преобразует между `.txt`, `.bin`, `.wav` и `.aiff`.

## BASIC и ассемблер

```sh
apple1-emu basic game.bas -o game.wav          # токенизированный листинг -> кассета
apple1-emu basic game.bas -o game.txt --ram 16 # дамп Woz, для 16 КБ
apple1-emu basic game.bas                      # только проверка
apple1-emu asm game.s -o game.wav              # исходник 6502 -> кассета
apple1-emu asm game.s -o game.bin -l game.lst  # двоичный файл + листинг
apple1-emu asm game.s -I ../lib                # проверка, доп. путь включения
```

{{basic (командная строка)|`basic`}} токенизирует листинг так же, как интерпретатор, и записывает блок `$004A-$00FF`, затем программу; `--ram 8|12|16|32` выбирает целевую машину (по умолчанию — самую маленькую из достаточных). {{asm (командная строка)|`asm`}} ассемблирует исходник ca65 (или xa); без `-o` только проверяет. Обе команды выводят строку, которую нужно набрать на настоящем Apple-1.

```text title="Вывод apple1-emu asm hello.s -o hello.txt"
33 octets, $0300-$0320 ; 2 fichier(s), 13 symboles
Cassette (après C100R) : 0300.0320R   puis 300R
écrit : hello.txt
```

То есть: «33 байта, $0300-$0320; файлов: 2, символов: 13 / Кассета (после C100R): 0300.0320R, затем 300R / записано: hello.txt».

## ASCII-арт

{{ascii}} `IMAGE`: `--cols`, `--rows` (23, чтобы сохранить приглашение), `--zoom`, `--cx`, `--cy`, `--brightness`, `--contrast`, `--gamma`, `--invert`, `--dither`, `--no-auto-level`, `--ramp simple|full|slideshow|LIST`, `--format asm|basic`, `--title`, `-o` (`.txt`, `.bas`, `.s`, `.wav`, `.aif`).

## ППЗУ

{{prom}} готовит файлы для прошивки настоящих ППЗУ 256 × 4 (82S129, 3601, 6301) в формате дампа по тетрадам:

```sh
apple1-emu prom split woz -o proms/     # PROM-A2.bin (D7-D4) и PROM-A1.bin (D3-D0)
apple1-emu prom split aci -o proms/     # PROM-A3.bin (D7-D4) и PROM-A4.bin (D3-D0)
apple1-emu prom join A2.bin A1.bin      # собрать прочитанное и сравнить
```

`--swap-a1-a7` нужен только для платы, разведённой по схеме Apple 1976 года, где адресные линии 1 и 7 ППЗУ A2 перекрещены.

Чтобы прошить EPROM от 2716 до 27C512 или EEPROM 28C из графического интерфейса (программатор TL866II+, T48 или T56 с `minipro`), см. программатор EPROM, раздел 2.6.

## Графический интерфейс

`apple1-emu-gui [OPTIONS] [FILE…]` загружает указанные файлы при запуске. Основные параметры (имена параметров французские):

| Параметр | Действие |
|---|---|
| `--zoom N\|ajuster`, `--taille WxH` | масштаб экрана (`ajuster` = по окну), размер окна |
| `--phosphore vert\|blanc\|ambre` | люминофор (зелёный, белый, янтарный) |
| `--screening`, `--sans-screening`, `--screening-options LIST` | винтажный экран Apple-1 и его настройки |
| `--gen2-screening` | винтажный экран на цветном мониторе GEN2 |
| `--theme clair\|sombre\|systeme` | светлая, тёмная или системная тема |
| `--taille-icones auto\|petite\|normale\|grande\|tres-grande` | размер значков и текста |
| `--barre-complete` | никогда не сжимать панель инструментов до одних значков |
| `--bibliotheque FOLDER`, `--basic FILE` | папка библиотеки, файл BASIC |
| `--carte-couleur`, `--sans-carte-couleur`, `--couleur-50hz` | карта GEN2 |
| `--langue CODE\|auto` | язык интерфейса (`--langue ru` для русского) |
| `--mode-rapide`, `--mode-cassette` | загрузка из библиотеки: мгновенная (по умолчанию) или через кассету на реальной скорости |
| `--cassette FILE` | вставляет кассету |
| `--ecran-separe`, `--debogueur` | экран в отдельном окне, отладчик открыт |
| `--editeur FILE`, `--ascii FILE` | открывает файл в редакторе или в инструменте ASCII |

Для демонстраций и снимков экрана некоторые параметры воспроизводят действия через несколько секунд: `--lancer-biblio S:NAME`, `--charger-biblio S:NAME`, `--parametres S:NAME`, `--preferences S` (и `--onglet-prefs interface|editeur|bibliotheque|cassette|gen2|avance`), `--editeur-lancer S`, `--editeur-recherche TEXT` (строка поиска открыта), `--editeur-menu` и `--ecran-menu` (открыты меню правого щелчка), `--menu-etat` (открыто меню «Состояние»), `--eprom` (открыт программатор EPROM), `--fenetre-fichiers` (открыто окно «Загрузить»), `--editeur-exporter S:FILE`, `--ascii-reglages R`, `--ascii-lancer S`, `--taper TEXT`, `--taper-a S:TEXT`, `--dbg-arret`, `--dbg-surveiller`, `--dbg-commande S:CMD`, `--capture IMAGE.png` (после `--delai S`) и `--quitter`.

# Неполадки и частые вопросы

## Окно не открывается

Нет драйвера OpenGL, или вы работаете в виртуальной машине. `run.sh` автоматически повторяет попытку с программной отрисовкой Mesa; вручную: `LIBGL_ALWAYS_SOFTWARE=1 ./apple1-emu-gui`. Винтажный экран остаётся плавным и при программной отрисовке.

## Клавиши не доходят до Apple-1

Щёлкните по экрану Apple-1. Когда активно текстовое поле или диалоговое окно, клавиатура идёт в это поле; строка состояния показывает, куда идёт клавиатура.

## «Integer BASIC не найден»

BASIC не поставляется. Положите свой `BASIC.wav` (или `.bin` размером 4096 байт) в библиотеку или укажите его кнопкой **BASIC** либо через **⚙ Настройки → Дополнительно → Integer BASIC**. После этого эмулятор находит его сам.

## Программа на BASIC останавливается с STOPPED AT

Во время её работы была нажата клавиша: на Apple-1 любая клавиша прерывает программу на BASIC. Наберите `RUN`, чтобы начать заново, или `GOTO` с номером строки, чтобы продолжить, не стирая переменные.

## Программа не запускается после загрузки

- Программа на BASIC: нужен `E2B3R` (тёплый вход), а не `E000R`, который стирает программу. BASIC должен быть в памяти **до** программы.
- Машинный код: проверьте адрес запуска в параметрах ⚙; это не всегда `300R` (`280R`, `1000R`, `2000R`…).
- Программа больше 8 КБ: ОЗУ добавляет ▶, но не ручная загрузка. Запустите её через ▶ или используйте `--ram 16`.

## Кассета не загружается на настоящем Apple-1

<ol class="steps">
<li>Громкость на максимум, все звуковые эффекты выключены, никаких уведомлений.</li>
<li>RETURN — во время заголовка, а не до начала воспроизведения и не после конца заголовка.</li>
<li>Точные диапазоны, по четыре цифры: <code>004A.00FFR</code>, никогда <code>4A.FFR</code>.</li>
<li>Попробуйте другой проигрыватель (VLC), затем <code>--rate 44100</code>, <code>--channels 1</code> или <code>--no-refresh</code>.</li>
<li>Проверьте уровень командой <code>apple1-emu info prog.aiff --aci-input stock</code> (раздел 5.8).</li>
<li>Если загрузка не заканчивается: RESET, затем повторите с большей громкостью.</li>
</ol>

## Экран заполнен инверсными @

Это цветной монитор GEN2: его память начинается с нулей, а код `$00` — это инверсный `@`. Программа ещё не заполнила текстовую страницу. На настоящей карте содержимое было бы случайным.

## Символы выводятся медленно

Это нормально: терминал Apple-1 выводит около 60 символов в секунду. Щёлкните **Вывод: ~60 симв./с** в строке состояния (или **Быстрый** в строке отображения экрана), чтобы вывод стал мгновенным, и переключитесь в быстрый режим (<kbd>F3</kbd>), чтобы ускорить всё.

## Звук кассеты не слышен

Он выключен на быстрой скорости, а также при отсутствии ALSA или звуковой карты: осциллограф это сообщает («без звука на максимальной скорости», «нет аудиовыхода»). Громкость задаётся в осциллографе; 🔊 на панели инструментов выключает или включает звук.

## Проект GitHub не собирается

«Проверить последнюю сборку» собирает через ca65/ld65 (пакет `cc65`), если не находит ни Release, ни артефакта. Установите `cc65` или добавьте `apple1.toml`, указывающий нужный файл. Некоторым исходникам нужен свежий ca65 (2.19 или новее); тогда ошибка ca65 показывается как есть.

## Чего эмулятор не делает

- Недокументированные коды операций 6502 обрабатываются как NOP нужной длины, а коды JAM останавливают процессор; их точное действие не воспроизводится (программы для Apple-1 их не используют).
- Компаратор ACI во время эмуляции идеален; только команда `info` моделирует его как аналоговую схему.
- Эмуляция проверена по ПЗУ, листингам и независимым инструментам (c2t, ca65, xa), но автор этого руководства ещё не проигрывал аудиофайлы на настоящий Apple-1.
