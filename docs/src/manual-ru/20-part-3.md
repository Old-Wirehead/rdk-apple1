# 6502 вкратце

<p class="lead">6502 в Apple-1 — 8-битный процессор с частотой 1,023 МГц, тремя регистрами, 56 инструкциями и адресным пространством 64 КБ. Эта глава даёт самое необходимое, чтобы читать и писать примеры этой части.</p>

## Регистры

| Регистр | Размер | Роль |
|---|---|---|
| **A** | 8 бит | аккумулятор: арифметика, сравнения, чтение и запись |
| **X**, **Y** | 8 бит | индексные регистры: счётчики циклов, смещение в таблице |
| **S** | 8 бит | указатель стека; стек занимает страницу `$0100-$01FF` |
| **PC** | 16 бит | счётчик команд: адрес следующей инструкции |
| **P** | 8 бит | флаги N V – B D I Z C |

{{!регистры (6502)}}

Флаги обновляются почти каждой инструкцией:

<dl class="ref">
<dt>N (отрицательный)</dt><dd>копия бита 7 результата; проверяется <code>BMI</code> / <code>BPL</code>.</dd>
<dt>V (переполнение)</dt><dd>знаковое переполнение при сложении или вычитании; <code>BVS</code> / <code>BVC</code>.</dd>
<dt>Z (ноль)</dt><dd>результат равен нулю; <code>BEQ</code> / <code>BNE</code>.</dd>
<dt>C (перенос)</dt><dd>перенос при сложении, отсутствие заёма при вычитании, выдвинутый бит; <code>BCS</code> / <code>BCC</code>.</dd>
<dt>D (десятичный)</dt><dd><code>ADC</code> и <code>SBC</code> работают в BCD. Woz Monitor выполняет <code>CLD</code> при запуске.</dd>
<dt>I (прерывания)</dt><dd>маскирует IRQ. У стандартного Apple-1 их нет.</dd>
</dl>

## Режимы адресации

| Режим | Синтаксис | Байты | Пример | Действие |
|---|---|---|---|---|
| неявный | `INX` | 1 | `inx` | X ← X + 1 |
| аккумулятор | `ASL A` | 1 | `asl a` | сдвигает A |
| непосредственный | `#знач` | 2 | `lda #$8D` | A ← $8D |
| нулевая страница | `zp` | 2 | `lda $06` | A ← память $0006 |
| нулевая страница, X | `zp,X` | 2 | `lda $06,x` | |
| абсолютный | `адр` | 3 | `lda $D010` | |
| абсолютный, X / Y | `адр,X` | 3 | `lda message,x` | индексированная таблица |
| косвенный индексный | `(zp),Y` | 2 | `lda ($06),y` | 16-битный указатель в нулевой странице плюс Y |
| индексный косвенный | `(zp,X)` | 2 | `lda ($06,x)` | таблица указателей |
| относительный | `метка` | 2 | `bne loop` | переход на −128…+127 байт |
| косвенный | `(адр)` | 3 | `jmp ($FFFC)` | только `JMP` |

**Нулевая страница** (`$0000-$00FF`) — самая ценная: её инструкции короче и быстрее, и только этот режим позволяет указатели `(zp),Y`. Woz Monitor использует только `$24-$2B`; Integer BASIC — гораздо больше (глава 16).

## Инструкции по группам

| Группа | Инструкции |
|---|---|
| загрузка, сохранение | `LDA LDX LDY STA STX STY` |
| пересылки | `TAX TAY TXA TYA TSX TXS` |
| стек | `PHA PLA PHP PLP` |
| арифметика | `ADC SBC` (с переносом: `CLC` перед `ADC`, `SEC` перед `SBC`) |
| инкременты | `INC INX INY DEC DEX DEY` |
| логика | `AND ORA EOR BIT` |
| сдвиги | `ASL LSR ROL ROR` |
| сравнения | `CMP CPX CPY` (C = 1, если регистр ≥ значения, Z = 1 при равенстве) |
| ветвления | `BEQ BNE BCC BCS BMI BPL BVC BVS` |
| переходы | `JMP JSR RTS RTI BRK` |
| флаги | `CLC SEC CLD SED CLI SEI CLV` |
| ничего | `NOP` |

{{!инструкции (6502)}}

!!! astuce "Беззнаковое сравнение"
    После `CMP #n` `BCC` переходит, если A < n, а `BCS` — если A ≥ n. Для «A > n» сравнивайте с n + 1: так и делают примеры с `cmp #'9' | $80 + 1`.

## NMOS 6502, а не 65C02

В Apple-1 стоит исходный 6502 (NMOS), и в эмуляторе тоже. Недокументированные коды операций выполняются как `NOP` нужной длины, а коды `JAM` останавливают процессор. Ассемблер принимает инструкции 65C02 после `.setcpu "65C02"` (`BRA`, `STZ`, `PHX`, `PLX`, `PHY`, `PLY`, `INC A`…) для платы с 65C02, но в эмуляторе они **не работают**:

```asm title="c02.s (тест)"
        .setcpu "65C02"
        .org $0300
        lda #$C1        ; "A"
        bra next        ; on an NMOS 6502: 2-byte NOP
        lda #$D8        ; "X"
next:   jsr $FFEF
        jmp $FF1F
```

Эта программа выводит `A` на 65C02 и `X` в эмуляторе: там `BRA` ($80) — это `NOP`, пропускающий свой операнд, и выполняется `LDA #$D8`.

## Карта памяти с первого взгляда

| Адреса | Содержимое |
|---|---|
| `$0000-$00FF` | нулевая страница (Woz Monitor: `$24-$2B`; BASIC: гораздо больше) |
| `$0100-$01FF` | стек |
| `$0200-$027F` | буфер строки Woz Monitor |
| `$0280-$1FFF` | свободно: ваши программы, часто с `$0280` или `$0300` (по умолчанию в эмуляторе 8 КБ ОЗУ; 4 КБ, до `$0FFF`, на стандартном Apple-1) |
| `$C000-$C0FF` | карта ACI (кассета); `$C100-$C1FF`: её программа |
| `$C250-$C257` | переключатели карты GEN2 |
| `$D010-$D013` | PIA: клавиатура и дисплей |
| `$E000-$EFFF` | Integer BASIC (если загружен) |
| `$FF00-$FFFF` | Woz Monitor |

Полная карта приведена в приложении A.
