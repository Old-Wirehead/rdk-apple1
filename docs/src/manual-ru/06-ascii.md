# Фото → ASCII

<p class="lead">Инструмент «Фото → ASCII» превращает фотографию в картинку Apple-1 из 40 × 24 символов, а затем в программу на BASIC или 6502, готовую к запуску или к экспорту на кассету.</p>

![Инструмент «Фото → ASCII»: фотография и рамка кадрирования, настройки и предпросмотр шрифтом 2513.](img/ru/brut/ascii-outil.png "large")

## Открытие изображения

**🎨 ASCII** открывает инструмент — закрепляемую панель, как и остальные. **Перетащите** фотографию `.jpg` или `.png` в окно или воспользуйтесь **📂 Открыть…** (фотография или готовый ASCII-арт в `.txt`).

Зелёная рамка на фотографии показывает преобразуемую часть: перетаскивайте её, чтобы сдвинуть, колесо мыши масштабирует.

## Настройки

| Настройка | Назначение |
|---|---|
| **Столбцы**, **Строки** | не больше 40 × 24. **23 строки** оставляют последнюю строку для приглашения, чтобы картинка не прокручивалась. |
| **Масштаб**, **Центр** | сохраняемая часть фотографии |
| **Яркость**, **Контраст**, **Гамма** | обычные настройки (гамма > 1 осветляет) |
| **Инверсия** | тёмное = много краски |
| **Автоуровни** | растягивает уровни серого (от 2 % до 98 %) до остальных настроек |
| **Дизеринг** | Флойд — Стейнберг: больше оттенков, больше шума |
| **Символы** | шкала **Полная** (26 уровней), **Простая** (10), из **Slideshow (Шменк)** или **Своя** |

Возможны только символы 2513: заглавные буквы, цифры и знаки, без строчных, без `"` и без `_`. Они упорядочены по числу горящих точек в шрифте Apple-1: уровень серого задаёт именно это число, а не форма.

!!! astuce "Для портрета"
    40 × 24 символа — это немного: кадрируйте по лицу (масштаб от 1,3 до 1,6), немного поднимите контраст и для светлой фотографии попробуйте гамму меньше 1. Лучше всего получается однотонный тёмный фон.

## Получаемая программа

- **BASIC**: по одной строке `PRINT "…"` на каждую строку картинки. Полная строка из 40 символов заканчивается на `;`, потому что экран сам переносит строку. Такая программа медленно вводится (около 2 с на строку).
- **6502**: исходник ca65 по адресу `$0300`, запускаемый командой `300R`. После очистки экрана цикл посылает в ECHO сжатую таблицу (серии одинаковых символов закодированы как «количество + символ»). Вывод мгновенный.

При 24 строках программа ждёт нажатия клавиши, прежде чем вернуться; при 23 приглашение оказывается на последней строке, и картинка остаётся целой.

Кнопки: **✎ Вставить в редактор** (новая вкладка BASIC или 6502), **▶ Запустить**, **📼 Экспорт WAV…**, **💾 Сохранить в библиотеку** (`.txt` в папке «Art ASCII»), **📋 Копировать текст**, **Показать код**.

## В командной строке

```sh
apple1-emu ascii photo.jpg                       # только картинка, на экран
apple1-emu ascii woz.jpg --zoom 1.3 --cx 0.45 --cy 0.32 \
          --contrast 1.3 --gamma 0.45 --rows 23 -o woz.txt
apple1-emu ascii woz.jpg -o woz.bas              # программа на BASIC
apple1-emu ascii woz.jpg -o woz.s                # исходник 6502
apple1-emu ascii woz.jpg -o woz.wav              # кассета 6502, запуск 300R
apple1-emu ascii woz.jpg -o woz.wav --format basic
```

Все параметры приведены в главе 12.

!!! apple1 "Слайд-шоу Дэйва Шменка"
    В 2014 году Дэйв Шменк написал для Apple-1 слайд-шоу из портретов. Библиотека добавляет его как проект GitHub (`dschmenk/Apple1-Slideshow`): он скачивается, а не поставляется, потому что у репозитория нет лицензии. **▶ Проверить последнюю сборку** ассемблирует его (синтаксис xa, переводится автоматически; те же 3456 байт, что и у xa 2.4.1) и запускает командой `280R`.
