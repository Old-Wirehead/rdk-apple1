# Справочник операторов и функций

<p class="lead">Все операторы, которые распознаёт Integer BASIC для Apple-1, взятые из таблицы ключевых слов интерпретатора, с тем, что они делают на самом деле. Каждый пример проверен.</p>

## Операторы

`PRINT` список `[;]`
{: .syntax }

{{PRINT}} выводит числа и строки. `;` соединяет элементы без пробела (`PRINT A;B` выводит `12` при A=1, B=2); `,` переходит к следующему столбцу с шагом 8 (`PRINT 1,2,3` выводит `1       2       3`). Конечный `;` подавляет перевод строки. `PRINT` без аргументов переходит на следующую строку.

`INPUT` `["подсказка",]` переменная `[,переменная…]`
{: .syntax }

{{INPUT}} читает число или строку. BASIC всегда выводит `?` после подсказки: `INPUT "NAME",N$` выводит `NAME?`. Строка, слишком длинная для своего `DIM`, даёт `STR OVFL ERR`.

`LET` переменная `=` выражение
{: .syntax }

{{LET}} необязателен: достаточно `A=5`.

`IF` выражение `THEN` оператор | номер
{: .syntax }

{{IF}} выполняет оператор, когда выражение не равно нулю (допускается `IF A THEN …`). `THEN 100` переходит на строку 100. **Внимание**: от условия зависит только первый оператор (глава 18, ошибка 4).

`GOTO` выражение — `GOSUB` выражение — `RETURN`
{: .syntax }

{{GOTO}} и {{GOSUB}} принимают **выражение**: `GOTO K*100`, `GOSUB 300+K` («вычисляемый GOTO» заменяет отсутствующий `ON … GOTO`). Несуществующая строка даёт `BAD BRANCH ERR`. Не больше восьми вложенных {{GOSUB}} (`>8 GOSUBS ERR` на девятом); `RETURN` без `GOSUB` даёт `BAD RETURN ERR`.

`FOR` перем `=` начало `TO` конец `[STEP шаг]` … `NEXT` перем
{: .syntax }

{{FOR}}/{{NEXT}}: тело выполняется **хотя бы один раз**, даже если начало уже за концом (`FOR I=5 TO 1` проходит один раз). `STEP` может быть отрицательным. Не больше восьми вложенных циклов (`>8 FORS ERR`). `NEXT` должен называть переменную; `NEXT` без `FOR` даёт `BAD NEXT ERR`.

`DIM` перем`(n)` `[,перем$(n)…]`
{: .syntax }

{{DIM}} создаёт целочисленный массив из `n` элементов, пронумерованных **от 1 до n** (`A(0)` даёт `RANGE ERR`), или резервирует `n` символов (не больше 255) для строки. Каждую строку нужно объявить до присваивания.

`REM` текст
{: .syntax }

{{REM}}: комментарий до конца строки (`:` после REM входит в комментарий).

`END`
{: .syntax }

{{END}} завершает программу. Программа, которая заканчивается без `END`, выводит `*** END ERR`: это безвредно, но заканчивайте свои программы оператором `END`.

`TAB` n
{: .syntax }

{{TAB}} — это **оператор** (а не функция PRINT, как в Applesoft): `TAB 10:PRINT "*"` выводит звёздочку в столбце 10.

`POKE` адрес`,`значение
{: .syntax }

{{POKE}} записывает байт (от 0 до 255, иначе `>255 ERR`). Адреса выше 32767 записываются отрицательными числами: адрес − 65536.

`CALL` адрес
{: .syntax }

{{CALL}} вызывает программу на машинном языке, которая возвращается по `RTS`. Пример: `POKE 768,96 : CALL 768` (96 = `RTS`). `CALL -256` корректно возвращает в Woz Monitor (`$FF00`).

## Функции

| Функция | Результат | Проверенный пример |
|---|---|---|
| {{PEEK}}`(адр)` | байт по адресу | `PEEK(76)+PEEK(77)*256` даёт HIMEM (4096) |
| {{RND}}`(n)` | случайное целое от 0 до n−1; `RND(0)`: `>32767 ERR`; `RND(-5)` даёт отрицательное число | `RND(6)+1`: игральная кость |
| {{SGN}}`(x)` | −1, 0 или 1 (в том числе для числа 256 и больше) | `SGN(-5);SGN(0)` выводит `-10` |
| {{ABS}}`(x)` | абсолютная величина | `ABS(-9)` = 9 |
| `KEY(n)` (только G2 Basic) | код нажатой клавиши без ожидания (см. ниже) | `K=KEY(0)` |
| {{LEN}}`(a$)` | длина строки | `LEN("ABC")` = 3 |
| {{USR}}`(x)` | вызывает `$0000`: без подготовленной программы **машина падает** | — |
| {{ASC}}`(`, {{SCRN}}`(` | есть в таблице, но дают `SYNTAX ERR` | — |

## Операции

| Приоритет | Операции |
|---|---|
| 1 | унарные `-` и `+`, `NOT` |
| 2 | `*` `/` `MOD` |
| 3 | `+` `-` |
| 4 | `=` `#` (не равно, также `<>`) `<` `>` `<=` `>=` |
| 5 | `AND` |
| 6 | `OR` |

{{MOD}}, {{AND}}, {{OR}} и {{NOT}}:

- Деление **отбрасывает дробную часть в сторону нуля**: `7/2` = 3, `-7/2` = −3. `MOD` берёт знак делимого: `-7 MOD 3` = −1.
- Сравнения дают 1 (истина) или 0 (ложь): `PRINT 5>3;5=3` выводит `10`. `NOT 0` = 1, `NOT 5` = 0.
- `AND` и `OR` логические, а не побитовые: `3 AND 0` = 0, `3 OR 0` = 1.
- `3*-2` принимается и равно −6.
- `^` есть в таблице, но **вешает машину** (глава 18, ошибка 2).
- Строки можно сравнивать только через `=` и `#`; `"ABC"<"ABD"` отвергается (`SYNTAX ERR`).

## Расширения RDK G2 Basic

Они работают только с **RDK G2 Basic** (оригинальный Integer BASIC отвечает `SYNTAX ERR`).

`KEY(n)`
{: .syntax }

`KEY(0)` возвращает **код клавиши**, которая была нажата (7-битный код ASCII: 65 для `A`, 13 для Return, 32 для пробела), и забирает его, или `0`, если клавиша не нажималась. Она никогда не ждёт, поэтому программа может работать и следить за клавиатурой. `KEY(1)` (любой другой ненулевой аргумент) **ждёт** клавишу.

```basic title="Ждать клавишу без INPUT"
10 K=KEY(0)
20 IF K=0 THEN 10
30 PRINT K
```

В оригинале клавиша, нажатая во время работы программы, **останавливает** её (`STOPPED AT n`), а `INPUT` блокируется до Return. В G2 Basic, как только программа вызвала `KEY`, нажатие клавиши её больше не останавливает: клавиатуру видит только `KEY`, а <kbd>Ctrl</kbd>+<kbd>C</kbd> (код 3), прочитанный `KEY`, останавливает программу при следующем вызове. Поэтому вызывайте `KEY` в главном цикле программы.

`LOMEM=` n — `HIMEM=` n
{: .syntax }

Непосредственные команды, принимающие выражение (`LOMEM=2048+512`); внутри программы они дают `SYNTAX ERR`, как в оригинале. Они описаны вместе с памятью в главе 16.

`LIST` `[`a`[,`b`]]` — `DEL` a`[,`b`]`
{: .syntax }

`LIST` выводит всё, `LIST n` — одну строку, `LIST a,b` — строки от `a` до `b`. `DEL n` удаляет одну строку, `DEL a,b` — строки от `a` до `b` (если `b` меньше `a`, только строку `a`). Выводимая строка длиннее экрана переносится как в оригинале (строки продолжения сдвигаются на шесть пробелов).

Срезы строк следуют оригиналу: `A$(I)` при `I` от 256 и больше или отрицательном даёт `>255 ERR`, а `A$(I,J)` при `J` меньше `I-1` даёт `STRING ERR`.

## Ключевые слова, которые ничего не делают

В таблице есть `COLOR=`, `PLOT`, `HLIN`, `VLIN` и `VTAB`, унаследованные от проекта BASIC для Apple II. На Apple-1 `COLOR=` и `PLOT` принимаются и ничего не делают, `VTAB` даёт `SYNTAX ERR`. Не используйте их в своих программах.
