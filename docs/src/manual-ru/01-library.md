# Библиотека

<p class="lead">Библиотека — отправная точка почти всего: она хранит ваши кассеты, дампы и исходники, узнаёт кассеты того времени и запускает программу одним щелчком, в том числе на BASIC.</p>

![Панель библиотеки: основная папка, папка «Art ASCII», распознанные кассеты и проект GitHub. Играет BASIC.wav.](img/ru/bibliotheque.png "small")

## Папки

Основная папка — `~/apple1/programmes`. Она создаётся при первом запуске, а примеры раскладываются по пяти папкам: **Art ASCII** (одиннадцать примеров ASCII-графики 40 × 24, глава 9), **BASIC** (программы `.bas` и `.hex.txt` для BASIC), **6502** (исходники `.s`/`.asm` с их `.bin`/`.hex`), **GEN2 COLOR** (тесты карты GEN2 от Bernie, `gen2-*.apl`, и цветные игры для G2 Basic) и **WAV** (все кассеты). На панели эти пять папок показаны прямо на верхнем уровне, в порядке **BASIC**, **6502**, **GEN2 COLOR**, **WAV**, **Art ASCII**: корневая папка (имя каталога на диске) над ними не отображается, а файлы, оставленные в ней россыпью, не перечисляются. Положите их в одну из пяти папок. Добавленная папка или проект GitHub сохраняют собственный заголовок. Уже существующая библиотека никогда не перестраивается, кроме того, что её папки **Assembleur** и **Uncle Bernie** (названия версий с 7.8 по 7.9.1) переименовываются в **6502** и **GEN2 COLOR** с сохранением содержимого. Чтобы выбрать другую: **⚙ Настройки → Папка библиотеки → 📂 Обзор…** (**⟲ По умолчанию** возвращает `~/apple1/programmes`).

**+ Папка** вверху панели добавляет другие папки; основная папка остаётся всегда. Библиотека — это дерево: папки и подпапки сворачиваются, и их состояние запоминается. Каждая папка хранит свои настройки в файле `programs.json`. Правый щелчок по добавленной папке позволяет открыть её в файловом менеджере или убрать из списка (на диске ничего не удаляется).

**Узкая панель.** Библиотеку можно сделать сколь угодно узкой (до минимальной ширины, ниже которой разделитель останавливается). Каждая запись при этом подстраивается: имя занимает всю ширину и обрезается «…», если слишком длинное (полное имя — в подсказке), маленькие значки ▶ ⬇ 📼 ⚙ переходят на следующую строку, а описание ограничено одной-двумя строками, тоже с «…», полный текст — в подсказке. В заголовке **+ Папка** и **+ Проект GitHub** превращаются в значки с подсказкой.

Показываются файлы: `.wav .aiff .bin .hex .txt .apl .bas .s .asm .prg`. Список обновляется сам каждые две секунды: скопируйте файл в папку, и он появится.

Для каждой программы список показывает имя, тип, области адресов, длительность кассеты, команду запуска и ваши заметки.

### Игры Claude IA

В папки **BASIC** и **6502** также попадают пять небольших игр, написанных Claude IA, каждая во французской и английской версиях: *Виселица* (`pendu.bas`, `hangman.bas`), *Спички* (`allumettes.bas`, `matches.bas`) и *Морской бой* (`bataille.bas`, `battleship.bas`) на BASIC; *Туннель* (`tunnel.s`, `tunnel-en.s`) и *Крестики-нолики* (`morpion.s`, `tictactoe.s`) на ассемблере 6502. Двойной щелчок по игре на BASIC запускает её на RDK G2 Basic (эмулятор запускает BASIC, загружает листинг и набирает `RUN`); исходники на ассемблере собираются встроенным ассемблером. Они подключают `apple1.inc`, который устанавливается вместе с ними. В папке **GEN2 COLOR** есть также *Четыре в ряд в цвете* (`puissance4-couleur.bas`) — игра для G2 Basic и карты GEN2 от Claude IA. Q и S двигают фишку над сеткой, пробел бросает её. Игры входят в проект и действуют на условиях его лицензии (приложение «Лицензия и благодарности»).

## Запуск программы

У каждой программы справа четыре маленьких значка:

| Значок | Действие |
|---|---|
| **▶** | **Загрузить и запустить**: при необходимости загружает программу, затем запускает её: RESET, затем её команда, набранная на клавиатуре (`300R` или `E2B3R` и `RUN` для программы на BASIC). Если программе нужен Integer BASIC, а его нет в `$E000`, эмулятор сначала загружает его. Листинг BASIC набирается в Integer BASIC, исходник 6502 ассемблируется. |
| **⬇** | **Загрузить**: помещает программу в память мгновенно, не запуская её. |
| **📼** | **Через кассету**: как на настоящей машине. Эмулятор нажимает RESET, набирает `C100R`, затем команду чтения ACI (например, `0300.031ER`), и кассета играет с реальной скоростью, со звуком и полосой прогресса. Файлы `.txt` и `.bin` сначала преобразуются в кассету. Неактивен для исходника (`.bas`, `.s`), у которого нет записи. |
| **⚙** | **Параметры**: области, адрес загрузки `.bin`, адрес и команда запуска, тип, нужен ли BASIC, заметки. |

{{!двойной щелчок}}Загрузка **мгновенная**, если вы не выбрали кассету значком 📼. **Двойной щелчок** по программе загружает её и запускает, если у неё есть команда запуска (как ▶). Кассета используется, только когда вы об этом просите; тогда магнитофон на панели инструментов показывает кассету и её позицию.

Когда редактор открыт, ▶, ⬇ или двойной щелчок по листингу BASIC или исходнику 6502 к тому же **открывают его во вкладке редактора**, помеченной 📚; если он уже открыт, просто показывается его вкладка.

**Правый щелчок** по программе предлагает остальное: загрузить, загрузить и запустить, вставить как кассету без набора команд, параметры, переименовать, удалить (с подтверждением), открыть папку.

## Параметры программы

![Параметры ⚙ Hamurabi: две области (нулевая страница BASIC, затем программа), запуск через E2B3R, затем RUN.](img/ru/brut/bibliotheque-params.png "large")

| Поле | Назначение |
|---|---|
| **Области** | Участки памяти, записанные как для ACI: `0300.031E` или `004A.00FF 0800.0FFF` для программы на BASIC. Каждая запись на кассете по порядку попадает в свою область. |
| **Адрес загрузки** | Для `.bin`, который не содержит адреса. |
| **Запуск** | Адрес и команда, которую набирает ▶. `\n` обозначает RETURN между двумя строками: `E2B3R\nRUN`. |
| **Тип** | **Машинный код**, **Программа G2 Basic** (выбор по умолчанию для листинга BASIC, так как эмулятор его содержит) или **Программа Integer BASIC** (для тех, кто предпочитает оригинал Apple: ▶ тогда загружает оригинальный Integer BASIC, выбранный в настройках). Тип, выбранный для программы, главнее общего параметра BASIC в настройках. |
| **Нужен BASIC** | ▶ сначала загрузит BASIC того типа, который указан у программы. |
| **Заметки** | Свободный текст, показываемый в списке. |

Значения заранее заполняются по файлу и проверяются при сохранении; **⟲ Значения из файла** читает их заново.

!!! attention "Всегда четыре цифры: 004A.00FF, никогда 4A.FF"
    Параметры отвергают `4A.FF`. Это не каприз: ПЗУ ACI не очищает свой шестнадцатеричный накопитель на точке, так что цифры продолжают сдвигаться, и она прочитала бы `$004A-$4AFF` (см. раздел 5.6). Поэтому эмулятор всегда пишет адреса четырьмя цифрами.

## Распознанные кассеты

Когда файл **распознан**, его параметры заполняются сами, а список показывает **✔ распознано**. Эмулятор декодирует записи и сравнивает их размеры и отпечатки SHA-256 со встроенной таблицей: 24 кассеты коллекции «Apple1Cassettes» на archive.org. Имя файла тогда совершенно не важно. Иначе он узнаёт **имя** (без учёта регистра, пробелов и дефисов) при тех же размерах записей; подсказка тогда сообщает, что содержимое отличается.

| Кассета | Области | Запуск |
|---|---|---|
| `BASIC.wav` (Integer BASIC) | `E000.EFFF` | `E000R` |
| `Hamurabi.wav`, `StarTrek.wav`, `Wumpus.wav`, `Slots.wav`, `Craps.wav`, `Bowling.wav`, `Buzzword.wav`, `WordCross.wav`, `AppleiEnhancedCheckers.wav`, `LunarlanderasciiGraphics.wav` | `004A.00FF 0300.0FFF` | `E2B3R ⏎ RUN` |
| `AceyDucey.wav`, `Blackjack.wav`, `HiLo.wav` | `004A.00FF 0800.0FFF` | `E2B3R ⏎ RUN` |

| `APPLE30TH.wav` | `0280.0FFF` | `280R` |

| `Microchess.wav` | `1000.18FF` | `1000R` |
| `LunarLander.wav` | `0300.09FF` | `300R` |
| `Mastermind.wav` | `0300.03FF` | `300R` |
| `Pasart.wav` | `0300.05FF` | `300R` |
| `Life.wav` | `2000.21FF` | `2000R` (12 КБ) |

Ваши собственные параметры никогда не перезаписываются: программа, которую вы настроили сами, сохраняет свои параметры, появляется лишь отметка «распознано». Программы, выходящие за базовые 8 КБ, при запуске автоматически получают нужное ОЗУ, как с платой расширения.

**Неизвестная кассета.** Эмулятор угадывает, что может: запись длиной 4096 байт, начинающаяся с `JMP`, — это Integer BASIC; две записи, первая из которых длиной 182 байта (`$4A-$FF`), — программа на BASIC, размещаемая по её указателям LOMEM и HIMEM. Список тогда показывает «(предположительно)»; проверьте через ⚙. Программа в машинных кодах без адресов не угадывается: укажите её область.

## Проекты GitHub

**+ Проект GitHub** принимает URL (`https://github.com/jefftranter/6502/tree/master/asm/jmon`) или просто `владелец/репозиторий`. Нужные файлы копируются в `~/.cache/apple1-emu/github/<владелец>/<репозиторий>/<коммит>/`, а проект становится узлом дерева, с коммитом, датой и сообщением. **⟳ Обновить** получает последний коммит; 🌐 открывает страницу репозитория. Вся работа с сетью идёт в фоне.

{{Проверить последнюю сборку}} пробует по порядку:

<ol class="steps">
<li>файлы последнего <strong>релиза</strong> репозитория (<code>.wav</code>/<code>.aiff</code>, затем <code>.bin</code>, затем <code>.hex</code>/<code>.txt</code>);</li>
<li>последний <strong>артефакт GitHub Actions</strong> (нужен токен);</li>
<li><strong>сборку из исходников</strong>: листинг BASIC набирается в Integer BASIC и запускается через <code>RUN</code>; исходник 6502 ассемблируется <strong>ca65/ld65</strong> (пакет <code>cc65</code>), по умолчанию с <code>-D APPLE1</code>; дамп Woz загружается.</li>
</ol>

![Проект GitHub: от адреса репозитория до работающей программы.](diagrams/ru/workflow-github.svg "diagram large")

Файл `apple1.toml` (или `apple1.cfg`) в корне репозитория указывает, что собирать:

```toml title="apple1.toml"
file    = "src/game.s"    # программа для запуска
load    = $0300           # адрес загрузки (иначе .org исходника)
run     = $0300           # адрес запуска (иначе адрес загрузки)
ld65    = "apple1.cfg"    # конфигурация ld65 (иначе -t none)
defines = "APPLE1"        # символы -D для ca65
```

!!! astuce "Токен GitHub необязателен"
    Публичным репозиториям он не нужен. Токен (переменная `GITHUB_TOKEN` или **⚙ Настройки**) повышает лимит запросов и даёт доступ к вашим приватным репозиториям и к артефактам. Он никогда не показывается и не пишется в сообщения, а `gui.json` тогда становится доступен для чтения только вашей учётной записи.

## Папка «Art ASCII»

В библиотеке есть и папка **Art ASCII**: рисунки в формате экрана (яблоко, плата Apple-1, микросхема 6502, кассета, ракета…) и портреты Стива Возняка и Стива Джобса, преобразованные из фотографий со свободной лицензией. ASCII-арт `.txt` при выделении показывает превью с кнопками **→ BASIC**, **→ 6502** и **🎨 Открыть в инструменте**; **▶** сразу запускает его версию для 6502. Инструмент описан в главе 9.
