# Перенос программы с Applesoft или Microsoft BASIC

<p class="lead">Большинство листингов 1970-х и 1980-х годов написаны на Microsoft BASIC (Applesoft, BASIC из «101 BASIC Computer Games»). Их можно перенести на Apple-1, если знать соответствия. Каждая «отвергнутая» строка ниже была набрана в настоящем BASIC.</p>

## Соответствия

| Applesoft / Microsoft | Integer BASIC Apple-1 | Примечание |
|---|---|---|
| `ON X GOTO 100,200,300` | `GOTO 100*X` (если номера строк позволяют) или серия `IF X=1 THEN 100` | отвергается |
| `GET A$` | `INPUT A$` | отвергается |
| `DATA` / `READ` / `RESTORE` | массив, заполненный присваиваниями, или нарезаемая строка | отвергается |
| `MID$(A$,I,N)` | `A$(I,I+N-1)` | отвергается |
| `LEFT$(A$,N)` / `RIGHT$(A$,N)` | `A$(1,N)` / `A$(LEN(A$)-N+1)` | — |
| `A$+B$` | `A$(LEN(A$)+1)=B$` | — |
| `CHR$(N)`, `ASC(A$)` | строка-образец (глава 18, ошибка 6) | отвергается |
| `STR$(N)`, `VAL(A$)` | прямо `PRINT N`; `INPUT N` | отвергается |
| `INT(X)` | не нужно: всё целое | отвергается |
| `RND(1)` (вещественное от 0 до 1) | `RND(N)` (целое от 0 до N−1) | — |
| `X^2` | `X*X` | вешает (ошибка 2) |
| `HOME` | 24 × `PRINT` или CLEAR SCREEN (<kbd>Ctrl</kbd>+<kbd>L</kbd>) вручную | отвергается |
| `PRINT TAB(10);"X"` | `TAB 10:PRINT "X"` | — |
| `STOP` | `END` | отвергается |
| `DEF FN` | `GOSUB` | — |
| `A<>B` | `A#B` (`<>` тоже принимается) | — |
| `IF A THEN X:Y` | обратное условие + переход (ошибка 4) | ловушка |
| `DIM A(10,10)` | `DIM A(121)` и `A(I*11+J+1)` | — |
| `A(0)` | индексы начинаются с 1 | `RANGE ERR` |
| `SCORE`, `NAME$` | `S`, `N$`: одна буква (+ цифра) | `SYNTAX ERR` |
| вещественные числа | целые ×10 или ×100 (фиксированная точка) | — |

## Метод

<ol class="steps">
<li><strong>Составьте список переменных</strong> исходной программы и назначьте каждой букву (+ цифру). Запишите таблицу в <code>REM</code> в начале.</li>
<li><strong>Замените DATA</strong> присваиваниями в подпрограмме инициализации или строкой, которую вы нарезаете.</li>
<li><strong>Найдите все <code>IF … THEN … : …</code></strong> и перепишите их с переходом (ошибка 4).</li>
<li><strong>Найдите все выходы из <code>FOR</code> через <code>GOTO</code></strong> и замените их на «конечное значение + <code>NEXT</code>» (ошибка 1).</li>
<li><strong>Сдвиньте индексы массивов</strong> на 1, если программа использует индекс 0.</li>
<li><strong>Проверьте в редакторе</strong>: он помечает слова, неизвестные Integer BASIC, прямо при наборе. <strong>▶ Запустить</strong> вводит программу: любая отвергнутая строка появляется на экране с <code>SYNTAX ERR</code>.</li>
<li><strong>Измерьте память</strong>: <code>apple1-emu basic prog.bas</code> показывает размер и нужное ОЗУ. Слишком велика для 8 КБ? <code>LOMEM=768</code> (глава 17) или машина на 16 КБ.</li>
<li><strong>Экспортируйте</strong> кассету (<strong>📼 Экспорт WAV</strong>) и запишите диапазоны для настоящей машины.</li>
</ol>

## Пример переноса

Типичный фрагмент на Microsoft BASIC:

```text title="Оригинал (Microsoft BASIC)"
100 READ N$,S
110 IF S>HI THEN HI=S:BEST$=N$
120 IF N$<>"END" THEN 100
130 PRINT "BEST: ";BEST$;" (";HI;")"
140 DATA "ANNE",12,"BOB",17,"CLAIRE",9,"END",0
```

На Apple-1: нет `READ`/`DATA`, нет длинных имён, а `IF` в строке 110 присваивал бы `BEST$` на каждом проходе (ошибка 4).

```basic title="Перенос на Integer BASIC (проверено)"
10 DIM N$(10),B$(10),S(3)
20 S(1)=12:S(2)=17:S(3)=9
30 H=0
40 FOR I=1 TO 3
50 GOSUB 200
60 IF S(I)<=H THEN 80
70 H=S(I):B$=N$
80 NEXT I
90 PRINT "BEST: ";B$;" (";H;")"
100 END
200 IF I=1 THEN N$="ANNE"
210 IF I=2 THEN N$="BOB"
220 IF I=3 THEN N$="CLAIRE"
230 RETURN
```

```mon
>» RUN
BEST: BOB (17)
```

## Уроки переносов

Восемь игр из *101 BASIC Computer Games* (DEC, 1975) были перенесены так во время разработки эмулятора: BAGLES, MUGWMP, HEX, BULCOW, STARS, TRAP, CHOMP и WAR. Каждая была сыграна в эмуляторе, экспортирована на кассету и перезагружена через ПЗУ ACI. Эти переносы не распространяются (исходные листинги несвободны), но они задали правила этой главы: переменные из одной буквы, массивы с 1, никаких `READ`/`DATA`, никаких `GOTO` из `FOR`, только один оператор под `IF` и `LOMEM=768` для самых больших.
