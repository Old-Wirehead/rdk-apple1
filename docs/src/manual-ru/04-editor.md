# Редактор

<p class="lead">Встроенный редактор позволяет писать программы на Integer BASIC и исходники 6502, проверяет их при каждом нажатии клавиши, запускает их на эмулируемом Apple-1 одним щелчком и экспортирует на кассеты для настоящей машины.</p>

## Вкладки и файлы

**📝 Редактор** открывает панель, закреплённую слева от экрана. Его панель инструментов компактна, чтобы оставить тексту как можно больше строк. Она начинается со значков, которые объясняются во всплывающих подсказках:

| Значок | Действие |
|---|---|
| **Новый** (первый значок) | Новая вкладка: «Программа на BASIC» или «Исходник на ассемблере 6502» |
| **📂** / **💾** / **💾…** | Открыть (`.bas`, `.txt`, `.s`, `.asm`, `.a65`, `.inc`) / Сохранить (<kbd>Ctrl</kbd>+<kbd>S</kbd>) / Сохранить как… |
| **✂**, копировать, **📋** | Вырезать, копировать, вставить |
| **🔍** | Найти и заменить (<kbd>Ctrl</kbd>+<kbd>F</kbd>, <kbd>Ctrl</kbd>+<kbd>H</kbd>) |
| **⟲ ⟳** | Отменить (<kbd>Ctrl</kbd>+<kbd>Z</kbd>), повторить (<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd>) |
| **A▲▼** | Размер текста: один компактный элемент, буква A с двумя маленькими треугольниками друг над другом; ▲ увеличивает, ▼ уменьшает |

За ними, в той же строке (или в следующей, если панель узкая), идут действия вкладки: **▶ Запустить**, **📼 Экспорт WAV** и **Память** для BASIC или **📃 Листинг**, **⏺ Точка останова** и **⏩ До курсора** для исходника 6502.

Каждый файл — это вкладка. Точка • отмечает изменённую вкладку; × закрывает её (если она не сохранена, нужен второй щелчок). Вкладка с пометкой **📚** открыта из библиотеки: открытие листинга или исходника из библиотеки (▶, ⬇ или двойной щелчок) открывает его вкладку, когда редактор виден, или показывает её, если она уже открыта. Вкладки, включая несохранённый текст, возвращаются при следующем запуске. Правый щелчок по вкладке предлагает **Сохранить как…** и **Закрыть**. В тексте **щелчок средней кнопкой** вставляет первичное выделение (Linux): курсор встаёт туда, куда вы щёлкнули, затем вставляется текст, выделенный последним в любом приложении.

Размер текста задаётся элементом **A▲▼**, <kbd>Ctrl</kbd>+колесо или <kbd>Ctrl</kbd>+<kbd>+</kbd> / <kbd>Ctrl</kbd>+<kbd>−</kbd> / <kbd>Ctrl</kbd>+<kbd>0</kbd>, когда фокус клавиатуры в тексте.

**Открепить** выносит редактор в отдельное окно, например на второй экран; **⊟ Закрепить** возвращает его. Клавиши, нажатые в этом окне, идут в редактор, а не в Apple-1.

## Поиск, замена и меню правого щелчка

**🔍** (или <kbd>Ctrl</kbd>+<kbd>F</kbd>) открывает над текстом строку поиска: <kbd>Enter</kbd> переходит к следующему совпадению, <kbd>Shift</kbd>+<kbd>Enter</kbd> — к предыдущему, **Aa** учитывает регистр, **Слово** ищет слова целиком, а счётчик показывает «3 из 7». <kbd>Ctrl</kbd>+<kbd>H</kbd> добавляет поле **Заменить на**, с кнопками **Заменить** (текущее совпадение) и **Заменить все**. <kbd>Esc</kbd> закрывает строку.

![Строка поиска, открытая на ECHO, и меню правого щелчка для исходника 6502.](img/ru/editeur-menu.png "medium")

**Правый щелчок** по тексту открывает меню со всеми командами и их сочетаниями клавиш. Меню действует на **выделение**, которое сохраняется при правом щелчке по нему: **Вырезать** и **Копировать** работают с выделенным текстом. Команды, зависящие от слова (переход к определению, справка), используют **слово под щелчком**, а не под курсором:

| Команда | Клавиши |
|---|---|
| Вырезать, Копировать, Вставить, Выделить всё | <kbd>Ctrl</kbd>+<kbd>X</kbd>, <kbd>C</kbd>, <kbd>V</kbd>, <kbd>A</kbd> |
| Найти, Заменить | <kbd>Ctrl</kbd>+<kbd>F</kbd>, <kbd>Ctrl</kbd>+<kbd>H</kbd> |
| Перейти к строке… | <kbd>Ctrl</kbd>+<kbd>G</kbd> |
| Закомментировать / раскомментировать (6502), REM / убрать REM (BASIC) | <kbd>Ctrl</kbd>+<kbd>/</kbd> |
| Увеличить отступ, Уменьшить отступ | |
| Перейти к определению метки (6502) или номера строки (BASIC) | <kbd>F12</kbd> |
| Справка по *слову* (для ключевого слова, инструкции или директивы: открывает её статью в справочнике) | |
| Показать в дизассемблере (6502) | |
| Перенумеровать… (BASIC: `GOTO`, `GOSUB` и `THEN` следуют за номерами) | |
| Точка останова на этой строке | <kbd>F9</kbd> |
| Ассемблировать и запустить (6502), Отправить и запустить (BASIC) | <kbd>F5</kbd> |

**Цвета.** Цвета текста следуют теме интерфейса. **⚙ Настройки → Редактор** предлагает, отдельно для BASIC и для ассемблера 6502, схемы *Автоматически (по теме)*, *Классическая (тёмная)*, *Светлая*, *Янтарная*, *Высокий контраст* или ваши собственные цвета, по образцу на каждый вид слов (глава 11).

## Программа на BASIC

![Редактор BASIC: ошибки на красном фоне, с номером строки и столбца внизу панели.](img/ru/editeur-erreur.png "large")

Текст раскрашен: номера строк, ключевые слова, числа, строки, `REM`, операции. Каждая строка **токенизируется** так, как это сделал бы Integer BASIC, собственным токенизатором, сверенным байт в байт с настоящим. Строка, которую BASIC отверг бы, становится красной, а ошибка указывает строку текста, номер строки BASIC и столбец; щелчок ставит туда курсор. Обнаруживаемые ошибки: синтаксис, недопустимое имя переменной, число больше 32767, команда прямого режима (`LIST`, `RUN`…) внутри программы, незакрытая строка, строка длиннее 255 байт, переполнение памяти.

- **Память**: автоматически (8 КБ с LOMEM `$0800` или `$0300`, если программа большая, иначе 12, 16 или 32 КБ) или принудительно.
- {{▶ Запустить}}: загружает Integer BASIC, если его нет (как кнопка BASIC), помещает токенизированную программу в память, при необходимости добавляет ОЗУ, затем набирает `E2B3R` и `RUN`. Это мгновенно: ничего не набирается построчно.
- {{📼 Экспорт WAV}}: кассета (`.wav` или `.aiff` для смартфона) из двух записей, с параметрами в библиотеке. Внизу панели показано, что набрать на настоящем Apple-1, например `C100R`, затем `004A.00FFR 0C3B.0FFFR`, затем `E2B3R` и `RUN`; **📋 Копировать** помещает это в буфер обмена.

## Исходник 6502

![Исходник 6502 в редакторе: цвета, результат ассемблирования и строка для настоящего Apple-1.](img/ru/brut/editeur-asm.png "large")

Исходник ассемблируется **при каждом изменении** встроенным двухпроходным ассемблером, который принимает синтаксис ca65 (и синтаксис xa, переводимый автоматически). Внизу панели показаны размер и адреса (`33 байт, $0300-$0320 — файлов: 2, символов: 13`), затем строка для настоящей машины (`C100R`, затем `0300.0320R`, затем `300R`).

- **Ошибки**: файл, строка и столбец; щелчок переводит туда, при необходимости открывая включаемый файл. Предупреждения (нулевая страница, закодированная как абсолютный адрес) — жёлтые.
- **📃 Листинг**: адрес, байты и исходный текст каждой строки, с включаемыми файлами и развёрнутыми макросами, затем таблица символов; щелчок возвращает к строке.
- **▶ Запустить**: помещает байты в память по начальному адресу (`.org`, по умолчанию `$0300`), при необходимости добавляет ОЗУ, затем набирает, например, `300R`.
- **📼 Экспорт WAV**: кассета, как для BASIC.
- **⏺ Точка останова** и **⏩ До курсора**: связь с отладчиком (глава 8).
- **Связь с отладчиком**: когда вы выделяете инструкцию в исходнике (или ставите курсор на её строку), порождённые ею байты подсвечиваются в **дизассемблере** отладчика и в **дампе hex / ASCII**, если эти панели видны; если байты лежат в другом месте памяти, панели прокручиваются к ним. Это возможно благодаря таблице строк исходника и адресов ассемблера.
