# Установка ПЗУ или оригинального Integer BASIC

<p class="lead">Ничего больше не требуется. Woz Monitor, ПЗУ кассеты ACI и RDK G2 Basic уже в программе. Эта страница для тех, кому нужен Integer BASIC от Apple или другое совместимое ПЗУ из внешнего источника.</p>

Комплект **не распространяет ни одного собственнического файла ПЗУ**. Apple-1, Integer BASIC 1976 года и коммерческие кассеты остаются у правообладателей. Ссылки ниже ведут на уже существующие сайты: свою копию вы берёте там. В комплекте её нет.

## Что уже встроено

- **Woz Monitor**, по адресу `$FF00`.
- **ПЗУ кассеты ACI**, по адресу `$C100`.
- **RDK G2 Basic**, свободный BASIC, совместимый с Integer BASIC; кнопка **BASIC** загружает его в `$E000`.

## Оригинальный Integer BASIC

1. Достаньте свою копию, например кассету `BASIC.wav` из коллекции «Apple1Cassettes» на archive.org: <https://archive.org/details/Apple1Cassettes>.
2. Положите файл в библиотеку или оставьте его где угодно.
3. Откройте **⚙ Настройки → Дополнительно → BASIC**, выберите **оригинальный Integer BASIC**, затем **📂 Выбрать…** и укажите файл (`.wav`, `.txt` или `.bin` на 4096 байт).
4. Кнопка **BASIC** загрузит этот файл. **Забыть** возвращает встроенный G2 Basic.

Сообщество Apple-1 собирается на <https://www.applefritter.com/>. Комплект ничего с этих сайтов не скачивает: ссылка — только указатель.
