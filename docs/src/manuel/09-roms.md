# Installer une ROM ou l’Integer BASIC original

<p class="lead">Rien n’est obligatoire. Le Woz Monitor, la ROM de la cassette ACI et le RDK G2 Basic sont déjà dans le programme. Cette page est pour qui veut l’Integer BASIC d’Apple, ou une autre ROM compatible, depuis une source extérieure.</p>

Le kit **ne redistribue aucun fichier ROM propriétaire**. Apple-1, l’Integer BASIC de 1976 et les cassettes du commerce restent à leurs ayants droit. Les liens ci-dessous mènent vers des sites qui existent déjà : vous y prenez votre propre copie, le kit ne la contient pas.

## Ce qui est déjà là

- **Woz Monitor**, en `$FF00`.
- **ROM cassette ACI**, en `$C100`.
- **RDK G2 Basic**, un BASIC libre compatible avec l’Integer BASIC, chargé par le bouton **BASIC** en `$E000`.

## Integer BASIC original

1. Procurez-vous votre copie, par exemple la cassette `BASIC.wav` de la collection « Apple1Cassettes » sur archive.org : <https://archive.org/details/Apple1Cassettes>.
2. Rangez le fichier dans votre bibliothèque, ou gardez-le où vous voulez.
3. Ouvrez **⚙ Préférences → Avancé → BASIC**, choisissez **Integer BASIC d’origine**, puis **📂 Choisir…** et désignez le fichier (`.wav`, `.txt` ou `.bin` de 4 096 octets).
4. Le bouton **BASIC** charge alors ce fichier. **Oublier** revient au G2 Basic intégré.

La communauté Apple-1 se retrouve sur <https://www.applefritter.com/>. Le kit ne télécharge rien depuis ces sites : le lien est seulement une indication.
