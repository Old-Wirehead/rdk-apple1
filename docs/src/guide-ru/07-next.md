# Что дальше? {: .newpage }

Теперь вы умеете загружать кассету, писать и запускать программу на BASIC и переносить её на настоящую машину. **Полное руководство** (`docs/Polnoe-rukovodstvo.pdf`) идёт гораздо дальше:

- **Руководство по Integer BASIC**: все операторы с примерами, ограничения, сообщения об ошибках, известные ошибки и способы их обойти, перенос программ с Applesoft.
- **Руководство по ассемблеру 6502**: встроенный ассемблер (синтаксис ca65, макросы, листинг), подпрограммы Woz Monitor, примеры, проверенные в эмуляторе.
- **Игры, чтобы играть и читать**: в библиотеке есть пять небольших игр от Claude IA (Виселица, Спички, Морской бой на BASIC; Туннель и Крестики-нолики на ассемблере), каждая на французском и английском.
- **Инструменты**: отладчик, библиотека и проекты GitHub, цветная карта GEN2 и графическая карта P-LAB, фото → ASCII, винтажный экран, командная строка.

## Главные сочетания клавиш

| Клавиша | Действие |
|---|---|
| Ctrl+R | RESET (возврат в монитор) |
| Ctrl+L | CLEAR SCREEN |
| F3 | реальная или максимальная скорость |
| Ctrl+V | печатает буфер обмена на клавиатуре Apple-1 (или: правый щелчок по экрану → Вставить) |
| Ctrl+плюс, Ctrl+минус, Ctrl+0 | масштаб экрана и масштаб по окну (в редакторе: размер текста) |
| F11 | полный экран |
| F1 | подробные подсказки (как кнопка ?) |
| Backspace | `_`, стирание в мониторе |
| Ctrl+F, Ctrl+H, Ctrl+G | в редакторе: найти, заменить, перейти к строке |
| F5, F9 | в редакторе: запустить вкладку, точка останова на строке |

## Команды, которые стоит запомнить

| Команда | Действие |
|---|---|
| `E000R` | запускает Integer BASIC (холодный старт: стирает программу) |
| `E2B3R` | возвращает в BASIC без стирания программы |
| `C100R` | запускает программу ACI (приглашение `*`) |
| `начало.конецR` | читает кассету в этот диапазон, например `0300.031ER` |
| `300R` | запускает программу в машинных кодах с адреса `$0300` |
