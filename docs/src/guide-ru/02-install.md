# Установка в Linux

## Распаковать и запустить

<ol class="steps">
<li><strong>Распакуйте архив.</strong> Щёлкните правой кнопкой по <code>apple1-emu.zip</code> и выберите «Извлечь сюда». Появится папка <code>apple1-emu</code>.</li>
<li><strong>Дважды щёлкните по <code>run.sh</code>.</strong> Если файловый менеджер спросит, что делать с файлом (например, в Linux Mint), выберите <strong>«Запустить»</strong> (а не «Показать»). Откроется окно Apple-1, без терминала.</li>
<li><strong>По желанию: добавьте эмулятор в меню.</strong> Откройте терминал в папке (правый щелчок → «Открыть в терминале») и наберите команду ниже. В разделе <em>Игры</em> меню появится пункт <strong>Retro Dev Kit Apple 1</strong>, а также команды <code>apple1-emu-gui</code> (окно) и <code>apple1-emu</code> (терминал).</li>
</ol>

```sh
./install.sh             # меню приложений + команды в ~/.local/bin
./install.sh --bureau    # то же, плюс значок на рабочем столе
./install.sh --desinstaller
```

Удаление (`--desinstaller`) убирает программы и пункт меню, но сохраняет ваши программы (`~/apple1/programmes`) и настройки (`~/.config/apple1-emu`). Ни одной команде не нужен `sudo`: всё устанавливается в вашу домашнюю папку. При первом запуске новой версии эмулятор предлагает начать заново с исходными настройками: библиотека сохраняется. Кнопка **Сбросить настройки** делает то же. Пустой файл с именем `portable` рядом с программой (или `APPLE1_PORTABLE=1`) хранит настройки, библиотеку по умолчанию и кэш в папке комплекта.

!!! astuce "Обновление со старой версии"
    Скрипты `lancer.sh` и `installer.sh` прежних версий теперь называются `run.sh` и `install.sh`. Запустите `./install.sh` ещё раз: он заменит старую установку, а также пункт меню и значок на рабочем столе, указывавшие на `lancer.sh`.

!!! astuce "Терминальная версия"
    `./run.sh --terminal` открывает эмулятор в терминале (не меньше 42 столбцов × 28 строк), без графического интерфейса. Удобно при подключении по SSH. Её клавиши и команды описаны в Полном руководстве.

## Если окно не открывается

`run.sh` замечает немедленный сбой (графический драйвер, виртуальная машина без ускорения) и сам повторяет запуск с программной отрисовкой Mesa (`LIBGL_ALWAYS_SOFTWARE=1`). Если и это не помогает, выводится сообщение, а журнал лежит в `~/.cache/apple1-emu/gui.log`.

| Признак | Что делать |
|---|---|
| Файловый менеджер открывает `run.sh` в текстовом редакторе | Правый щелчок → Свойства → Права: отметьте «Разрешить выполнение файла как программы», затем снова дважды щёлкните и выберите «Запустить». |
| «Permission denied» в терминале | `chmod +x run.sh install.sh bin/*/apple1-*` |
| Чёрное или очень медленное окно | Нормально для виртуальной машины: программная отрисовка остаётся плавной для экрана Apple-1. При необходимости выключите «Винтажный экран». |
| Нет звука кассеты | Звук идёт через ALSA; без звуковой карты он просто отключён. Загрузка всё равно работает. |

## Где хранятся ваши файлы

| Расположение | Содержимое |
|---|---|
| `~/apple1/programmes` | **Библиотека**: ваши кассеты, программы и примеры (создаётся при первом запуске). |
| `~/.config/apple1-emu/gui.json` | Настройки: масштаб, цвета, расположение панелей, вкладки редактора. |
| `~/.cache/apple1-emu/` | Преобразованные кассеты, скачанные проекты GitHub, журнал `gui.log`. |
