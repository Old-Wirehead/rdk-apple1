# Первый запуск

При первом запуске окно открывается развёрнутым, и окно **Ваше рабочее пространство** предлагает пять расположений: **По умолчанию**, **Игра**, **BASIC**, **Ассемблер** и **Отладка**. Каждая пронумерованная миниатюра показывает расположение, говорит, для чего оно, и указывает минимальный размер экрана, который ему нужен: щёлкните нужную. Снимите флажок **Показывать это окно при запуске**, если не хотите больше его видеть; **⊞ Расположение ▾ → Выбрать рабочее пространство…** откроет его снова. Расположение можно сменить в любой момент через меню **⊞ Расположение ▾**. Расположение по умолчанию делает все инструменты видимыми сразу. Каждая область — это закрепляемая панель, которую можно переместить, сгруппировать во вкладки или вынести в отдельное окно. Цветной экран (GEN2 / P-LAB) — прямоугольник номер 7 в миниатюрах, которые его показывают, и в легенде; номера с 1 по 6 не меняются. Это окно не остаётся поверх других. Если окно узкое, панель инструментов прокручивается: кнопка **»** показывает группу «Кассета».

!!! astuce "Освободить место"
    Чтобы просто играть, закройте редактор и отладчик кнопками группы «Окна» (4): экран станет больше. В списке масштаба (8) пункт **По окну** выбирает наибольший целый масштаб, который помещается, **F11** включает полный экран, **⊞ Расположение ▾ → По умолчанию** (4) всё возвращает; в том же меню есть и расположение **Игра** (экран Apple-1 и библиотека). Если кнопки слишком мелкие или слишком крупные для вашего экрана, измените **⚙ Настройки → Интерфейс → Размер значков и текста**.

!!! note "Доступ к сети при первом запуске"
    При самом первом запуске эмулятор обращается к GitHub (`api.github.com`, `raw.githubusercontent.com`), чтобы получить демонстрационный проект (`dschmenk/Apple1-Slideshow`, указан в «Проекты GitHub» в **⚙ Настройки**), и показывает ход загрузки в строке состояния. Больше ничего не отправляется. Без сети он просто пропускает это; удалите проект из этого списка, чтобы прекратить загрузку навсегда.

## Монитор Woz Monitor

Обратная косая черта `\` — это приглашение **Woz Monitor**, 256-байтовой программы, с которой стартует Apple-1. Щёлкните по экрану и печатайте: строчные буквы становятся заглавными, **Enter** — это RETURN, **Backspace** даёт `_`, который стирает последний символ, как в 1976 году.

Монитор понимает четыре вида команд:

| Вы набираете | Результат |
|---|---|
| `300` | показывает байт по адресу `$0300` |
| `300.30F` | показывает байты с `$0300` по `$030F` |
| `300: A9 C1` | записывает `A9` в `$0300`, затем `C1` в `$0301` |
| `300R` | запускает программу, начинающуюся с `$0300` (*Run*) |

## Ваша первая программа в машинных кодах

Наберите эти две строки, каждую с Enter в конце:

```mon
» 300: A9 C1 20 EF FF 4C 1F FF

0300: 00
» 300R

0300: A9A
```

Последнюю букву `A` напечатала ваша программа. Восемь байтов — это три инструкции 6502:

| Байты | Инструкция | Назначение |
|---|---|---|
| `A9 C1` | `LDA #$C1` | загружает код буквы «A» (с установленным битом 7, как ожидает Apple-1) |
| `20 EF FF` | `JSR $FFEF` | вызывает ECHO — подпрограмму монитора, печатающую один символ |
| `4C 1F FF` | `JMP $FF1F` | возвращает в монитор, который ждёт следующую команду |

Монитор сначала показывает байт по начальному адресу (`0300: A9`), затем ваша программа печатает `A`. Встроенный ассемблер (Полное руководство) избавляет от вычисления этих байтов вручную.

!!! apple1 "На настоящем Apple-1"
    Команды те же самые: эмулятор выполняет настоящее ПЗУ Woz Monitor. Настоящая машина выводит около 60 символов в секунду. Эмулятор держит этот темп, когда в строке отображения экрана выбрано **Обычный**; **Быстрый** показывает всё сразу. Настройка общая для экрана Apple-1 и экрана GEN2.
