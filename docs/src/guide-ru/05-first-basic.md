# Ваша первая программа на BASIC

Integer BASIC, BASIC Стива Возняка, умещается в 4 КБ, а встроенный **RDK G2 Basic** эмулятора запускает те же программы. Он знает только целые числа (от −32767 до 32767), зато быстр и приятен в работе. Встроенный редактор избавляет от набора прямо на экране Apple-1, где одна опечатка означает перепечатку всей строки.

## Пишем программу

Нажмите **📝 Редактор** на панели инструментов, затем значок **Новый** (первый) в редакторе, выберите «Программа на BASIC» и наберите эту программу (она есть и в `docs/exemples/en/basic/premier.bas`). Apple-1 знает только латинские заглавные буквы, поэтому тексты в программах остаются английскими.

```basic title="premier.bas"
10 REM MY FIRST PROGRAM
20 PRINT "HELLO, APPLE-1!"
30 PRINT
40 FOR I=1 TO 8
50 PRINT I;" SQUARED = ";I*I
60 NEXT I
70 PRINT
80 DIM N$(20)
90 INPUT "YOUR FIRST NAME",N$
100 PRINT "NICE TO MEET YOU, ";N$;"!"
110 END
```

Ключевые слова, числа, строки и комментарии выделяются каждый своим цветом (цвета меняются в **⚙ Настройки → Редактор**); под текстом редактор показывает размер программы и память, оставшуюся для переменных.

!!! astuce "Правый щелчок в тексте"
    В меню редактора есть вырезать, копировать и вставить, **Найти** (Ctrl+F) и **Заменить** (Ctrl+H), переход к строке (Ctrl+G), REM / убрать REM для блока, **Перенумеровать…** (`GOTO`, `GOSUB` и `THEN` следуют за номерами), точка останова на строке (F9) и **Отправить и запустить** (F5).

## Запускаем

Нажмите **▶ Запустить**. Программа сразу попадает в память (при необходимости после BASIC), затем редактор сам набирает `E2B3R` и `RUN`:

![Редактор слева, работающая программа справа.](img/ru/brut/editeur-premier.png "large")

Программа спрашивает ваше имя. Щёлкните по экрану Apple-1, наберите его и нажмите Enter:

```mon
YOUR FIRST NAME?WOZ
NICE TO MEET YOU, WOZ!
```

!!! attention "Три особенности Integer BASIC"
    - **Строкам нужно задать размер**: без `DIM N$(20)` ввод строки через `INPUT` останавливается с `*** STR OVFL ERR`.
    - **Имена переменных** — одна буква, за которой может идти цифра: `A`, `B2`, `N$`. `TOTAL` — синтаксическая ошибка.
    - **Завершающий `END` обязателен**: без него программа заканчивается сообщением `*** END ERR`.

## Если есть ошибка

Редактор проверяет каждую строку прямо при наборе по правилам настоящего BASIC. Ошибочная строка становится красной, а сообщение объясняет проблему, с номером строки и столбца:

![Две найденные ошибки: незакрытая строка и слишком длинное имя переменной.](img/ru/editeur-erreur.png "medium")

Программа с ошибками не запускается: сначала исправьте красные строки. Ошибки во время выполнения появляются на экране Apple-1: `*** BAD BRANCH ERR` — `GOTO` на несуществующую строку, `*** >32767 ERR` — переполнение или деление на ноль. **Отладчик** (Полное руководство) позволяет затем идти строка за строкой, следя за переменными.

![Рабочий цикл: написать, запустить, исправить, затем экспортировать на настоящую машину.](diagrams/ru/workflow-basic.svg "diagram")

!!! astuce "Остановить программу"
    Во время `RUN` нажатие любой клавиши останавливает программу с сообщением `STOPPED AT 50` (текущая строка). Если программа зависла, **Сброс** (Ctrl+R) возвращает в монитор, а `E2B3R` снова входит в BASIC **без стирания** программы.
