# Instalar uma ROM ou o Integer BASIC original

<p class="lead">Não é preciso mais nada. O Woz Monitor, a ROM de cassete da ACI e o RDK G2 Basic já estão no programa. Esta página é para quem quiser o Integer BASIC da Apple, ou outra ROM compatível, a partir de uma fonte externa.</p>

O kit **não redistribui nenhum ficheiro de ROM proprietário**. O Apple-1, o Integer BASIC de 1976 e as cassetes comerciais continuam a pertencer aos seus titulares de direitos. As ligações abaixo apontam para sítios que já existem: é lá que obtém a sua própria cópia. O kit não a contém.

## O que já está integrado

- **Woz Monitor**, em `$FF00`.
- **ROM de cassete da ACI**, em `$C100`.
- **RDK G2 Basic**, um BASIC livre compatível com o Integer BASIC, carregado em `$E000` pelo botão **BASIC**.

## O Integer BASIC original

1. Obtenha a sua própria cópia, por exemplo a cassete `BASIC.wav` da coleção «Apple1Cassettes» no archive.org: <https://archive.org/details/Apple1Cassettes>.
2. Ponha o ficheiro na sua biblioteca, ou guarde-o onde quiser.
3. Abra **⚙ Preferências → Avançado → BASIC**, escolha **Integer BASIC original**, depois **📂 Escolher…** e indique o ficheiro (um `.wav`, um `.txt` ou um `.bin` de 4096 bytes).
4. O botão **BASIC** carrega então esse ficheiro. **Esquecer** volta ao G2 Basic integrado.

A comunidade do Apple-1 reúne-se em <https://www.applefritter.com/>. O kit não descarrega nada destes sítios: a ligação é só uma indicação.
