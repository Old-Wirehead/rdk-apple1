# Art ASCII — origine et licences

Dessins originaux de Retro Dev Kit Apple 1 (même licence que le logiciel) :
pomme, carte-apple1, puce-6502, cassette, fusee, chat, crane,
ordinateur, hello-woz.

Portraits (conversions 40x23 par l'outil « Photo → ASCII » de Retro Dev Kit Apple 1,
œuvres dérivées sous la même licence CC BY-SA 3.0) :

- portrait-wozniak.txt — d'après « Steve Wozniak by Gage Skidmore.jpg »,
  photo de Gage Skidmore, CC BY-SA 3.0,
  https://commons.wikimedia.org/wiki/File:Steve_Wozniak_by_Gage_Skidmore.jpg
  https://creativecommons.org/licenses/by-sa/3.0/
  (réglages : zoom 1,3, centre 0,45 × 0,32, contraste 1,3, gamma 0,45, 23 lignes)
- portrait-jobs.txt — d'après « Steve Jobs Headshot 2010-CROP (cropped 2).jpg »,
  photo de Matthew Yohe, CC BY-SA 3.0,
  https://commons.wikimedia.org/wiki/File:Steve_Jobs_Headshot_2010-CROP_(cropped_2).jpg
  https://creativecommons.org/licenses/by-sa/3.0/
  (réglages : zoom 1,4, centre 0,38 × 0,40, contraste 1,3, gamma 0,6, 23 lignes)

Le diaporama historique de Dave Schmenk (2014), avec ses portraits de Woz
et Jobs, est ajouté comme projet GitHub de la bibliothèque
(dschmenk/Apple1-Slideshow) : il est téléchargé depuis GitHub, pas fourni
avec l'émulateur (le dépôt n'indique pas de licence).
